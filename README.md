# linkedin1 — Add Experience

Complete LinkedIn-inspired profile project built with React, Vite and Tailwind CSS. The project includes sample profile and work-history content that you can customize.

## Included functionality
- Responsive LinkedIn-inspired profile page
- Add Experience form with title, company, employment type, location, start date, end date and description
- Currently working here checkbox
- Required-field and date-range validation
- Add multiple experiences
- Edit and delete experiences
- Experiences sorted by latest start date
- localStorage persistence after refresh
- Unsplash profile, cover and office images
- Tailwind CSS styling and Lucide icons

## Run
1. Extract the ZIP and open the `linkedin1` folder in VS Code.
2. Open terminal in this folder:
   `npm install`
3. Start Vite:
   `npm run dev`
4. Open the localhost URL printed in the terminal (usually http://localhost:5173).

## Build
`npm run build`

## Vercel deployment
Push this folder to its own GitHub repository and import it into Vercel.
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

Images and Google Fonts require internet access. Experience data is saved in the current browser only; it does not sync between users/devices. Profile, education, company and experience details are sample placeholders that can be edited.
